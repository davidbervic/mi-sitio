04

Blue grid background

Used for heroes, CTA sections, and feature highlight sections. Always exactly this — do not vary the grid color, opacity or size.

64px × 64px grid, rgba(255,255,255,.07) lines 
/* Every blue section uses this exactly */
.nx-grid-bg {
  background-color: #0574fd;
  background-image:
    linear-gradient(rgba(255,255,255,.06) 1px, transparent 2px),
    linear-gradient(90deg, rgba(255,255,255,.06) 1px, transparent 2px);
  background-size: 64px 64px;
}
05

Black borders and offset shadows

Every interactive or card element has a 1.5px solid black border and a flat offset box-shadow. This is the brand's most recognizable trait. No exceptions.

Drop SM
4px 4px 0 black
Cards, pills, buttons
Drop MD
7px 7px 0 black
Tier cards, panels
Drop LG
11px 11px 0 black
Hero snapshot, modals
On dark bg
7px 7px 0 white/90
CTA buttons on black
/* Border rule: ALL cards, buttons, pills */
border: 1.5px solid #050505;
border-radius: 16px; /* cards */
border-radius: 10px; /* buttons */
border-radius: 999px; /* pills and tags */

/* Hover state: always translate + grow shadow */
&:hover {
  transform: translate(-2px, -2px);
  box-shadow: 7px 7px 0 #050505;
}
&:active {
  transform: translate(3px, 3px);
  box-shadow: none;
}

08

Spacing and layout

Everything uses clamp() for fluid scaling. The max-width container is always 1200px centered.

/* Section padding (standard) */
padding: clamp(64px, 9vw, 112px) clamp(16px, 4vw, 44px);

/* Inner container */
.sv-inner { max-width: 1200px; margin: 0 auto; }

/* Section head max width */
.section-head { max-width: 720px; margin: 0 auto 52px; }

/* Content columns: standard card gap */
gap: 24px; /* between tier cards */
gap: 16–18px; /* between smaller cards */

/* Hero padding */
padding: clamp(48px, 7vw, 96px) 0 clamp(56px, 8vw, 104px);
09

Rules and anti-patterns

✓
Every section head has an eyebrow pill with an icon (star SVG or similar) before the text
✓
All cards have 1.5px solid #050505 border and a flat black box-shadow
✓
Hero is always blue grid with white Archivo Black headline. Trust/credential indicators belong inside the hero, not as a separate strip below
✓
CTA section is always black (#050505) background with white headline and green or accent-colored primary button
✓
Prices are always in JetBrains Mono inside a pill or `sv-tier-fee` box with accent-pale background
✓
Hover state on every card and button: transform: translate(-2px,-2px) + larger shadow
✗
Never use gradient text. No background-clip: text anywhere
✗
Never use em dashes (—). Use a comma, a period, or a colon instead
✗
Never stack more than 2 white/gray sections without a blue or black section in between
✗
Never use rounded corners larger than border-radius: 30px (--nx-radius-xl). No fully circular sections
✗
Never put body text directly on a blue background. Blue sections contain only headlines, eyebrow pills, CTAs, and white card panels
✗
Never add a new section background color outside the five defined: blue, black, white, light gray (#F4F4F4), or a program accent
10

What to fix on service pages

Compared to the main site, the service pages currently have these gaps:

Current state (problem)
  • • Trust strip is a separate black section below the hero, feeling disconnected
  • • Too many consecutive white/gray sections without a blue or black break
  • • No stats/metrics bar showing proof numbers
  • • Differentiator and Social Proof sections sit far apart, diluting their impact
  • • Platforms section is a plain 4-column grid with no visual hierarchy
  • • Delivery steps use a horizontal 6-step layout that is hard to read at a glance
Target state (fixes)
  • • Trust badges inline at the bottom of the hero copy, before the fold
  • • Insert at least one blue grid section mid-page (methodology or tools)
  • • Merge differentiator + social proof into one "Why Muvap" section
  • • Replace platforms grid with a two-column "Your CRM + What we add" layout
  • • "Where are you today?" scenario selector above tier cards (interactive)
  • • Delivery steps: vertical timeline with team role cards below
